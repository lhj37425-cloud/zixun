# 学习者画像

## 我是谁

- 只有我一个人用这个系统。
- 编程基础很少，主要靠 AI（Claude Code、TRAE）写代码和读代码。
- 每天能投入大约 5 小时以上学习。
- 在意 token 成本，不想只绑死一个 agent。
- 学完、用完的内容，习惯自己整理进 Obsidian。

## 我要去哪

- 目标：用半年到一年，转到 **FDE（Forward Deployed Engineer）** 类岗位。
- FDE 要能听懂客户业务，判断该用什么 AI 方案，并很快搭出能演示的原型。
- 所以每天的学习重点是：**拆真实 AI / agent 项目**，顺带扫一眼值得知道的前沿资讯。不是刷新闻，也不是背框架名词。

## 什么对我有用

- 能看清「它解决谁的什么问题」，而不只是技术炫技。
- 体积别太大，最好能在本机跟着跑起来。
- 讲解要用零基础能听懂的话；新概念要能记进术语表。
- 和 agent、工具调用、产品形态相关的，比纯底层训练论文更优先。

## 什么对我不太合适

- 强依赖高端显卡、大规模集群才能跑的项目（当主推要谨慎）。
- 没有说明、很难安装、只适合资深工程师深挖的巨型单体。
- 和 AI / agent / 落地应用关系很弱的普通工具。
