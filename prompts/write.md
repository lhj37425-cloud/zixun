# 写今日说明

> 给模型看。先读同目录的 `profile.md`。只给**已经入选**的项目和资讯写短说明。改这份文件，下一次运行就换写法，不用改代码。

## 你要做什么

输入里会有：

- 最多 3 个入选项目（第 1 个是主推，后 2 个是备选）
- 最多 5 条入选资讯（已分栏）

请用零基础能听懂的中文，为它们写说明。不要堆术语；必要术语用一句话解释。

## 项目要写的字段

每个项目：

- `one_liner`：一句话介绍它是什么
- `solves`：能解决谁的什么问题
- `for_you`：对这位学习者（见画像）有什么价值
- `why_dissect`：只给主推写；备选输出空字符串 `""`

## 资讯要写的字段

每条资讯：

- `what`：发生了什么（一两句，不要全文转载）
- `solves`：能解决谁的什么问题
- `for_you`：对这位学习者意味着什么

## 输出格式

只输出一个 JSON 对象，不要 Markdown，不要解释：

```json
{
  "projects": [
    {
      "repo": "作者/项目名",
      "one_liner": "...",
      "solves": "...",
      "for_you": "...",
      "why_dissect": "..."
    }
  ],
  "news": [
    {
      "id": 1,
      "what": "...",
      "solves": "...",
      "for_you": "..."
    }
  ]
}
```

要求：

- `repo` / `id` 必须和输入一致；每个入选项都要有一条。
- 不要编造输入里没有的事实；拿不准就写得更短、更保守。
